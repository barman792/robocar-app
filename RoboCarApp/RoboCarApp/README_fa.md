# اپ اندروید RoboCar (نسخه ۱.۲)

رابط کامل کنترل داخل خود اپ است؛ پس همه‌ی امکانات (جویستیک، رادار، ابزارها، تنظیمات) حتی وقتی ماشین خاموش است دیده می‌شود. اگر ماشین وصل نباشد، کارت «ماشین وصل نیست» مراحل اتصال را نشان می‌دهد، دکمه‌ی «تنظیمات Wi-Fi گوشی» دارد و مدام خودکار دوباره تلاش می‌کند. «حالت نمایشی» بدون ماشین همه‌ی کنترل‌ها را امتحان می‌کند.

همچنین: تمام‌صفحه، صفحه همیشه روشن، اتصال مستقیم به Wi-Fi ماشین (حتی با داده موبایل)، فرمان با چرخاندن گوشی، لرزش هنگام لمس.

ساخت APK و نصب: `RoboCar_Setup_Guide_FA.pdf` (قسمت ۲). خلاصه: مخزن GitHub ▸ آپلود همه‌ی محتویات این پوشه (از جمله `.github`) ▸ Actions ▸ Build APK ▸ Run workflow ▸ دانلود `app-debug.apk`. نسخه‌ی قبلی اپ را اول Uninstall کنید.

رابط از `RoboCar/web_ui.h` ساخته می‌شود: `python3 tools/sync_ui.py مسیر/web_ui.h` و دوباره APK بسازید.
