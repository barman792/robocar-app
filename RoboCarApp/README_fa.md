# اپ اندروید RoboCar

اپ یک «پوستهٔ» سبک است: به Wi-Fi ماشین وصل می‌شود (حتی اگر داده موبایل روشن باشد) و صفحهٔ کنترل خود ماشین (`192.168.4.1`) را تمام‌صفحه نشان می‌دهد. هر تغییری در `web_ui.h` ماشین، بدون ساخت دوبارهٔ اپ در اپ هم اعمال می‌شود.

## راه ۱ (بدون نصب چیزی): ساخت APK در GitHub، رایگان
1. در github.com حساب بسازید و یک مخزن (repo) جدید بسازید.
2. محتویات همین پوشه (`app/`، `build.gradle`، `settings.gradle`، `gradle.properties` و `.github/`) را در آن آپلود کنید (Add file ▸ Upload files).
3. تب **Actions** ▸ «Build APK» ▸ Run workflow. بعد از ~۳ دقیقه، پایین صفحهٔ اجرا در Artifacts فایل **RoboCar-apk** را دانلود کنید (zip است؛ داخلش `app-debug.apk`).
4. APK را به گوشی بفرستید و نصب کنید (اجازهٔ «نصب از منبع ناشناس» را بدهید).

## راه ۲: Android Studio
پوشه را Open کنید ▸ Build ▸ Build APK(s). خروجی: `app/build/outputs/apk/debug/app-debug.apk`.

## استفاده
Wi-Fi گوشی را به `RoboCar` وصل کنید، اپ را باز کنید. اگر ماشین پیدا نشد، صفحهٔ «تلاش دوباره» می‌آید. وقتی اپ را ببندید یا از صفحه بروید، ارتباط قطع می‌شود و ماشین خودش می‌ایستد.

## راه فوری بدون APK
در Chrome گوشی `http://192.168.4.1` را باز کنید ▸ منو ▸ «Add to Home screen».
